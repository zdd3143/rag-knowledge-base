# ---- 核心（阶段 1~9 都用得到）----
sentence-transformers     # BGE-M3 向量化 + bge-reranker-v2-m3 重排
pymupdf                   # PDF 解析（阶段 2）
numpy                     # 索引矩阵化运算（阶段 3 提速 325 倍）
jieba                     # 中文分词（手写 BM25 用，阶段 4）
requests                  # 调 DeepSeek API
fastapi                   # HTTP 服务（阶段 8）
uvicorn                   # ASGI server
